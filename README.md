# 👋 Hi, I'm Sebastian Gutierrez

## 💫 About Me

I'm a Full Stack Software Developer with professional experience designing and building scalable, maintainable web applications using C#, .NET, Java, Spring Boot, Node.js, Express, React, Angular, and Astro.

I specialize in backend development, RESTful API design, microservices, and software architecture, applying Clean Architecture, SOLID principles, and Clean Code practices to build robust, modular, and maintainable solutions.

Throughout my professional experience and personal projects, I've worked with different backend technologies, including ASP.NET Core, Entity Framework Core, Node.js, Express.js, Java, and Spring Boot. I've also developed modern frontend applications using React, Angular, TypeScript, Astro, and modern UI libraries.

I'm familiar with relational and NoSQL databases such as SQL Server, PostgreSQL, MongoDB, and DynamoDB, as well as database design, query optimization, ORM frameworks, and database migrations.

I also have experience with cloud technologies and serverless architectures, particularly within AWS, including AWS Lambda and other cloud services, alongside containerization with Docker and scalable application deployments.

Additionally, I actively incorporate AI-powered development workflows into my software engineering process. I work with AI coding assistants and agentic development tools such as Claude Code, Google Antigravity, and OpenCode, as well as local LLM environments using Ollama and LM Studio.

I'm familiar with AI-driven development methodologies and workflows, including Spec-Driven Development (SDD) and AI-assisted / Agentic Development, using specifications, reusable skills, custom commands, agent instructions, and structured development plans to improve productivity, maintain code quality, and automate complex engineering tasks.

I also explore AI integration within applications, including LLM-powered features, API integrations, and intelligent agents.

I enjoy solving complex problems, exploring emerging technologies, and collaborating with development teams to build high-quality software that delivers real business value.

Currently, I'm expanding my expertise in cloud architecture, distributed systems, serverless computing, AI engineering, and autonomous AI agents.
