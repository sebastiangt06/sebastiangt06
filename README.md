# 👋 Hi, I'm Sebastian Gutierrez

## 💫 About Me

I'm a **Full Stack Software Developer** with professional experience building scalable web applications using **.NET, C#, React and Angular**.

I specialize in designing and developing **REST APIs**, implementing **Clean Architecture**, and creating maintainable, modular applications following **SOLID** and **Clean Code** principles.

Throughout my professional experience, I've worked on backend development with **ASP.NET Core**, **Entity Framework Core**, **SQL Server**, and **MongoDB**, while also building responsive and reusable frontend applications with **React**, **Angular**, **TypeScript**, and modern UI libraries.

I enjoy solving complex problems, learning new technologies, and collaborating with teams to build high-quality software that delivers real business value.

Currently, I'm expanding my knowledge in cloud technologies, software architecture, and AI integration into web applications.
